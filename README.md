# ⚽ FIFA World Cup Analysis Project


## 📌 Overview

This project analyzes FIFA World Cup data using **Power BI**.  
It highlights player statistics, team performance, awards, and match outcomes with interactive dashboards.


## 📂 Dashboard Pages

1. **Winners & Managers** – Season‑wise champions, runner‑ups, managers, and logos  
2. **Points Table** – Wins, losses, draws, goals, and points  
3. **Participated Countries Map** – Global view of nations across editions


## 🛠️ Tools Used

- Power BI  
- DAX Functions (SELECTEDVALUE, CALCULATE, CONCATENATEX)  
- SQL & Excel for preprocessing


## 🚀 Features

- Interactive visuals with KPIs  
- Dynamic titles using DAX  
- Player‑level insights (Goals, Awards, Fair Play, Hat‑tricks)  
- Clean storytelling with professional layout
